# ESP32-CYD API Dashboard

A highly customizable, modular API dashboard and web control panel designed for the **ESP32 Cheap Yellow Display (CYD - ESP32-2432S028R)**. Monitor your home server, weather, Pi-hole, or smart home endpoints in real-time, trigger webhooks (GET/POST/PUT), and manage your layout entirely from a local web configuration UI.

## Features:

- **Dynamic Widget Layout:** Configure 1/3, 1/2, 2/3, or full-width widgets directly from your browser.
- **Advanced HTTP Methods:** Supports `GET`, `POST`, and `PUT` requests with custom headers and JSON payloads for both data fetching and action buttons.
- **Web-Based Config Panel:** Host an intuitive local web server to edit widgets, change themes, update Wi-Fi credentials, and re-order cards instantly.
- **Smart Template Parser:** Parse nested JSON objects and arrays using lightweight dot notation, negative indexing (`.-1`), null-coalescing fallbacks (`??`), and custom display filters (`| join`, `| count`, rounding decimals, and text casing).
- **Auto-Scrolling Idle Mode:** Smoothly cycles through your dashboard if left unattended, pausing at the top for easy reading.
- **Theming System:** Built-in support for Dark, Light, Ocean, Cyberpunk, and Retro terminal themes.
- **SD Card Storage:** Saves your configuration securely to an onboard micro SD card.

## Hardware Requirements:

- **ESP32-2432S028R** (commonly known as the "Cheap Yellow Display" or CYD) featuring a 2.8-inch TFT touch screen and ILI9341 display driver.
- Micro SD Card (formatted to FAT32) containing your `index.html` and `config.json` (optional).

## Template Syntax Guide:

Inside your widget templates, you can use bracket expressions to pull data from your API responses:

| Syntax | Example | Description |
| :--- | :--- | :--- |
| **Basic Path** | `{status}` | Pulls a top-level JSON key. |
| **Nested Object** | `{main.temp}` | Traverses nested JSON objects using dot notation. |
| **Array Indexing** | `{servers.0}` | Accesses specific array indices (supports negative indexing like `.-1` for the last item). |
| **Null Coalescing** | `{temp ?? N/A}` | Provides a fallback default value if the key is missing or null. |
| **Array Join** | `{tags \| join}` | Joins array elements with commas (`tag1, tag2`). |
| **Array Count** | `{items \| count}` | Returns the total count of items in an array. |
| **Decimal Rounding** | `{temp \| 1}` | Rounds floating-point numbers to a specified number of decimal places. |
| **Text Casing** | `{status \| upper}` | Transforms text to `UPPERCASE` or `lowercase`. |

*(Note: You can combine filters and defaults like this: `{temp | 1 ?? N/A}°F`)*

## Getting Started:

1. Clone or download this repository.
2. Install all required Arduino libraries, first timers see [this page](https://randomnerdtutorials.com/cheap-yellow-display-esp32-2432s028r/) for LVGL and TFT_eSPI configuration.
3. Copy the `index.html` file onto the root of your MicroSD card.
4. Open the `.ino` file in the Arduino IDE, update your default settings if needed, and compile/flash it to your ESP32-CYD.
5. Connect to the device's Wi-Fi AP or access its local IP address in your browser to start building and arranging your widgets!

There is an example configuration file called `config.json.example` if you want to see some example widgets. Just copy it as  `config.json` to the MicroSD card and boot the device!
